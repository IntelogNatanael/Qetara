# Penpot Design Assets

Este directorio guarda referencias de diseno para la app movil y futuras iteraciones de frontend.

Estructura:
- `references/black-and-white-mobile-templates.penpot`
- `references/circum-icons.penpot`
- `references/prototype-examples-v1.2.penpot`
- `references/50-social-media-icons.penpot`

Uso previsto:
- explorar patrones de layout movil
- tomar referencias de iconografia
- construir wireframes y prototipos de UX
- derivar un sistema visual antes de tocar la UI final

Recomendacion de trabajo:
1. crear un archivo maestro de producto en Penpot para `Conectar`, `Enviar`, `Chat` y estados vacios
2. reutilizar estos archivos solo como referencias, no como fuente de verdad final
3. normalizar componentes y tokens visuales antes de implementar cambios grandes en Compose

Nota de publicacion:
- estos archivos provienen de descargas locales y deben revisarse sus licencias antes de publicarlos en GitHub, F-Droid o distribuirlos junto al proyecto
