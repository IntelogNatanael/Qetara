# Qetara icon shortlist

SVGs exportados directamente desde `Qetara Mobile Design System` en Penpot.

Uso sugerido:

- `wifi-on.svg`: ruta Wi-Fi activa o disponible
- `wifi-off.svg`: sin red o ruta no disponible
- `chat.svg`: acceso a chat o canal
- `send.svg`: enviar mensaje o archivo
- `repeat.svg`: reintentar o resincronizar
- `lock.svg`: sesión o recurso protegido
- `unlock.svg`: sesión o recurso habilitado
- `warning.svg`: advertencia o bloqueo recuperable
- `info.svg`: estado informativo
- `check.svg`: éxito o listo
- `settings.svg`: ajustes o gestión avanzada
- `folder.svg`: archivos, adjuntos o carpeta recibida
